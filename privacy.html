Privacy Policy

Personal command line tool operated by Devayan Mandal · Last updated 17 September 2026

In short: this is a private tool used by one person, its owner. No data is collected from anyone else, nothing is sold, and nothing is shared with third parties.

What this is

This policy covers a personal command line tool (the "Tool") operated by Devayan Mandal, an individual based in Mumbai, India. The Tool is used solely by its owner to access the owner's own Google account for personal productivity.

The Tool is not a public service. It has no other users, no sign up, and no accounts beyond the owner's own Google account.

What Google data is accessed

When the owner authorizes the Tool through Google's OAuth consent flow, the Tool may access the following data in the owner's own Google account:

  • Gmail messages, threads, and labels
  • Google Calendar events
  • Google Drive files and metadata
  • Google Docs and Google Sheets content
  • Google Contacts

Only the scopes explicitly approved during authorization are accessible. Access can be revoked at any time, as described below.

How the data is used

Data is used only to perform actions the owner explicitly requests, such as searching mail, reading a message, listing calendar events, or reading a document. There is no automated background collection, profiling, or analytics.

How the data is stored

OAuth refresh tokens are stored locally on the owner's own computer, in the Windows Credential Manager. Tokens are not transmitted to, or stored on, any server operated by the owner or by any third party.

Message and document content is read on demand and is not retained in any external database.

What is never done with the data

  • Data is never sold, rented, or traded.
  • Data is never shared with third parties, except as required by law.
  • Data is never used for advertising, marketing, or profiling.
  • Data is never used to train machine learning models.
  • Data is never transferred to anyone other than the account owner.

Limited Use disclosure

The Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke the Tool's access to the Google account at any time by visiting myaccount.google.com/permissions and removing the app. Revoking access immediately invalidates the stored token.

Locally stored tokens can also be deleted at any time by removing the Tool's credentials from Windows Credential Manager.

Children

The Tool is not directed at children and is not made available to any other person.

Changes to this policy

If this policy changes, the updated date at the top of this page will change as well.

Contact

Questions about this policy can be sent to devtechedge@gmail.com.
